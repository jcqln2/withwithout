# Independence

This repository measures Optimum's public claims about mump2p. Optimum does not commission it, and Optimum does not get a veto over the results.

## Disclosures (as of 2026-10-22)

- **Funding.** None recorded. No payment from Optimum is recorded. Update this section before publishing any result if that changes, including cloud credits, hardware, or a grant.
- **Conflicts.** None recorded.
- **Optimum access.** No API key, join key, or cluster id is in this repo. None has been requested yet. The operator of this project still needs to request a Hoodi credential from the Optimum console and to get the terms below in writing before any treatment node starts.
- **Remote telemetry.** Gateway `remote_push` ships logs and metrics to Optimum. It stays disabled for this project unless this file is updated to say otherwise.

## Terms that must be agreed before Phase 2

1. A credential may be used to join the mesh for measurement.
2. Optimum gets a factual-error review window before publication. That window is not a veto. Changes made after review are logged in this file.
3. Support or credentials do not include a right to suppress a null or negative result.
4. Image digests, client versions, and the gateway version are published with the data.

## Integrity checklist

- [x] Pre-registered hypotheses committed before treatment data collected (`docs/hypotheses.md`)
- [ ] Optimum access terms disclosed here after they are actually agreed; no payment from Optimum; no veto on findings
- [ ] Any later funding or conflict of interest disclosed
- [ ] Raw data and code public; versions pinned (client versions, gateway image digest)
- [ ] A/A calibration published with the results
- [ ] Negative or null results published with equal prominence
- [ ] Optimum given a factual-error review window before publication, with all changes logged

Phase 0 checks only the first box. The others wait until there is something to publish.
